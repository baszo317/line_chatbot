# 高明補習班資料庫結構（v0.6）

> 這份文件由資料庫裡的欄位說明（`COMMENT ON`）產生，和 `sql/schema.sql` 一致。

## 先看這裡

- **資料庫在哪**：`.env` 的 `DATABASE_URL`。目前是這台電腦上的 PostgreSQL（`localhost:5432`，資料庫名稱 `gaoming`）。上傳的圖片也存在資料庫裡。
- **年級**：`6` = 國小（國小部都是六年級）、`7`～`9` = 國一～國三。學生存的是「入學那一學年」的年級，每年 8/1 由 `v_students` 自動升一級，國三之後顯示「已畢業」。
- **金額**：一律是整數（新台幣元）。**今天**：一律用 `tw_today()`（台灣時間）。
- **怎麼改資料**：全部都可以在後台 http://localhost:8000/admin 改。公告、行事曆、常見問題、榜單在後台存檔時，其實是寫進「補習班資料」資料夾再同步，所以也可以直接改資料夾裡的檔案；學生、家長、班級名單是直接寫進資料庫。不建議直接改資料表。
- **規模**：39 張資料表、17 個檢視表（`v_` 開頭，AI 和後台從這裡讀）。「預留」的表是第二期以後（請假、成績、訂餐、學費）才會用到，現在是空的。

## 常用函式

| 函式 | 用途 |
| --- | --- |
| `tw_today()` | 台灣時間的今天 |
| `school_year_of(日期)` | 這天屬於哪個學年度（民國年，8/1 起算），例：2026-10-18 → 115 |
| `grade_label(年級)` | 6 → 國小、8 → 國二、10 以上 → 已畢業 |
| `generate_sessions(開始, 結束)` | 依每週課表產生每一堂課（第二期） |
| `issue_binding_code(…)`、`redeem_binding_code(…)` | 家長綁定 LINE 的一次性綁定碼（第二期） |
| `charge_meals(…)`、`cancel_meal_order(…)` | 訂餐扣款、取消退款（第二期） |
